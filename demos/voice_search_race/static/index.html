How this is measured

Every lane gets the identical query at the same instant. The number on each lane is that vendor's own API latency, measured in the server around the HTTP call, so the voice pipeline and the browser are excluded. Each vendor runs its lowest-latency tier: Keenable realtime, Tavily ultra-fast, Exa instant.

With the mic, this is a real Gradium voice agent (Gradbot). Its search tool fires all three; the agent gets Keenable's results the moment they land and speaks, while the other lanes keep filling in. From the question list, the browser runs the same race without a microphone.

The one-sentence answer on each lane comes from the same small model with the same prompt, from that lane's top five results only. "Hear it" plays that lane's measured silence first, then the sentence in the agent's voice. Answer quality is a placeholder until the full set has been scored.
