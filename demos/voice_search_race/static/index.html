Methodology

Quality

tau2-bench with a new web_support domain: an "AnswerLine" consumer helpdesk with 20 tasks whose answers sit on real public pages, verified against official sources on 9 October 2026. Ten are evergreen facts, ten changed since 2025 (FSCS limit, passport fee, stamps, Congestion Charge, TV licence, Delta bag fee, Wise limits, Costco UK, Netflix prices, Ryanair bag size). The harness is fixed: Sonnet 5.5 agent, Haiku 5.5 user simulator, Sonnet 5.5 judge. Only the agent's web_search backend changes, at voice-grade settings (fast tiers, 5 results, 400-character snippets). The judge checks the current figure was given, not the old one. With no search tool at all the same agent scored 53% overall and 10% on the changed facts. Trials: Keenable 60 conversations, Tavily 43, Exa 19; with 20 tasks only gaps above about 15 points are significant.

Speed

The 30 caller questions in the "Run now" set, each sent to all three APIs at the same instant, two passes, from a Mac on a home connection in Hertfordshire. The number is each vendor's own API time, measured around the HTTP call; the voice pipeline and the browser are excluded. Each vendor runs its lowest-latency tier: Keenable realtime, Tavily ultra-fast, Exa instant. A voice turn has roughly 800 ms before the caller notices silence. In the tau2 runs Keenable's own p50 was 153 ms, Tavily 327 ms, Exa 487 ms.

Cost

Per-search cost is what the vendor reports in the API response where it does (Exa, Tavily), otherwise list price. Per-conversation cost multiplies that by the searches the agent actually made in tau2; Tavily's thin ultra-fast results made the agent search about four times per conversation, which also roughly quadrupled its LLM spend and doubled wall time.
