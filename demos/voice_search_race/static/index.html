How it works

Every lane gets the identical query at the same instant. The big number is the vendor's own API latency, measured in the server around the HTTP call only; the voice pipeline and the browser are excluded. Each lane runs the tier a voice-agent builder would pick: Keenable realtime, Perplexity fast, Tavily ultra-fast, Exa instant. The radio switch flips all four to standard tiers.

With the mic, this is a real Gradium voice agent (Gradbot). Its web_search tool fires all four; the agent gets Keenable's results the moment they land and speaks, while the other lanes keep filling in. With a picked phrase, the browser runs the same race over REST, so it works without a microphone.

The one-sentence answer per lane comes from the same small model with the same prompt, from that lane's top five results only. Its latency is shown separately and is not part of the race. "Hear it" plays the measured silence first, then the sentence. Cost per 1K is the vendor-reported cost where the API returns one (Exa, Tavily), otherwise list price.
